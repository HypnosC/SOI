# Chronicles of SOI · 设计 v5：无限时间纸 + 独特的记录方式

> 用户原话：「想有个无限画笔的感觉，思想投影在上面，再加上独特的记录方式，感觉这个软件会火」

---

## 一、核心概念：「无限时间纸」

Excalidraw 的画布是**无限纸**——没有坐标、没有含义，随便画。
**你的画布是「无限时间纸」——水平方向有年轮。**

```
┌────────────────────────────────────────────────────────────┐
│  前500        公元元年        500        1000       1500     │  ← 水平＝时间，无限延展
│   │             │             │           │           │      │
│   │   ┌──────┐  │             │  ┌──────┐ │           │      │  ← 垂直＝自由，你自己分层
│   │   │ 春秋 │  │             │  │  唐  │ │           │      │
│   │   └──────┘  │             │  └──────┘ │           │      │
│   │             │  ┌────────┐ │           │           │      │
│   │             │  │ 你随手 │ │           │           │      │
│   │             │  │ 画的东西│ │           │           │      │
│   │             │  └────────┘ │           │           │      │
└────────────────────────────────────────────────────────────┘
```

**为什么这个组合成立：**
- 你**随便画**（不限形状、不限位置、不限顺序）——这是"思想投影"
- 但因为水平方向有年轮，**你画的东西天然带时间含义**
- 垂直方向留给你自由——**你想怎么分层就怎么分层**（政治一层、文化一层、地理区域分层……）

**这和所有现有工具都不同：**
| 工具 | 水平轴 | 垂直轴 |
|---|---|---|
| Excalidraw / Miro | 无意义 | 无意义 |
| Aeon Timeline | 时间 | 固定泳道（不可自由画） |
| Geacron | 时间（滑块） | 地图 |
| **你的** | **时间** | **自由（可画、可分层）** |

## 二、核心交互：「落位」——乱画 → 一键成结构

**这是整个产品的钩子。**（原型已跑通）

```
第 1 步：乱画
   你读完一章，把脑中的五六个东西随手拖出来，
   斜着一路排下去，不管对齐、不管形状。      ← 零认知负担

第 2 步：按一下「落位」
   每个块按它的水平位置吸附到最近的刻度，
   自动上色（时代色相）、自动标注年份跨度，
   时间真重叠的自动下移一层。               ← 一个动作

第 3 步：结构浮现
   一堆乱画变成了一张整齐的历史结构图。       ← "哦，原来是这样"
```

**关键设计：吸附粒度必须比视觉网格细。**
原型里视觉网格是 200 年，但吸附用 50 年——否则秦（前 221–前 206）这种短命王朝会被吸到跟西汉同一格，看起来像重叠。

**这一步可以复用地图**：块落位时，如果它的标题匹配到地名，可以顺便获得地理坐标 → 地图上出现一个点。**画布 + 时间轴 + 地图，三者用"落位"这一个动作串起来。**

## 三、★「独特的记录方式」候选清单

你问的"独特的记录方式"，我想了六条。**按"独特度 × 可行性"排序：**

### 候选 1｜手势时长（画一条线＝一个时期）★★★★★

**不用打字，用手势表达你的感觉。**

- **横着画一条线，长度＝持续时间** —— "唐朝很长"你就画长一点
- **线越粗＝你觉得它越重要**
- **画个圈＝一个事件**（圆圈大小＝影响）
- **画个叉＝一次中断/灭亡**

> **你不会打字的时候，手会先动。** 这是最贴近"思想投影"的方式。
> 林奈（Linné）当年就是用等长的横条表示植物花期，后来这成了甘特图——**横条是人类表达"一段"的原始方式**。

**技术：** 画完 → 提示"它叫什么？" → 得到 `{text, y0, y1, weight}`，直接落位。
**成本：** 低（原型里的"拖出新块"已经是一半了）

### 候选 2｜先画后命名（形状即类型）★★★★☆

**不选分类，用形状表达分类：**
- 圆 = 事件
- 长条 = 时期
- 菱形 = 转折点
- 虚线框 = "我不确定"
- 加粗边 = 战争/冲突

**技术：** 识别形状（或干脆不识别，让形状本身就是语义）
**成本：** 极低。**而且形状本身就是一种"思想投影"**——你觉得这事是个"团"就画圆，是个"段"就画条。

### 候选 3｜粘贴即结构化 ★★★★☆

**从书上复制一段话，粘进来，自动抽出时间/地点/人物。**

```
粘贴：「万历十五年，海瑞在南京去世」
  → 1587 · 海瑞去世 · @南京 · 〔来源：粘贴〕
```
**规则 + 正则就够，不需要大模型**（年份 `\d+年`、地名 `@` 或词表匹配、人名用词表）。

**成本：** 中。**价值：** 高——**"边读书边记"的最佳入口**，因为读书时你在看文字，复制比打字自然。

### 候选 4｜涂鸦即数据（画曲线＝趋势）★★★★☆

**画一条曲线表示"国力/影响力随时间变化"。**

- 唐朝：先低后高再低的一条抛物线
- 你**画的形状本身就是数据**，直接叠在时间轴上

> **这是"思想投影"最直接的实现**——你不描述趋势，你**画出趋势**。
> 而且它天然表达"我的感觉"，不是"权威数据"。

**成本：** 中（需要把笔画采样成折线，存成点集）

### 候选 5｜语音一句 ★★★☆☆

说一句"万历十五年海瑞在南京死了" → 自动落到时空坐标。
**技术：** 浏览器 Web Speech API（中文识别可用），规则解析。
**成本：** 低。**问题：** 桌面场景不自然（戴耳机说话怪），移动端更合适。

### 候选 6｜时间标注笔（在轴上直接写）★★★☆☆

**直接在时间轴的刻度上写字**，像在日历上圈日期。
**成本：** 低。**问题：** 手写识别的准确率是坑。**建议先不做识别，把笔迹存成图片。**

### 我的推荐

> **先做候选 1（手势时长）+ 候选 2（形状即类型）。**
>
> 理由：
> 1. **它们一起构成"我真的在画，不是在填表"**——这是你要的"无限画笔"感觉的核心
> 2. **零识别成本**（不用 OCR、不用 NLP），纯几何
> 3. 原型里"拖出新块"已经做了一半
>
> **候选 3（粘贴结构化）放第二步**——它价值很高，但它是"读书入口"，不属于"画"这条线，可以并行。

## 四、三层关系（画布 / 时间轴 / 地图）

```
         自由画布                 时间轴                地图
    ┌──────────────┐       ┌──────────────┐     ┌──────────────┐
    │ 思想投影      │       │ 结构对齐      │     │ 空间定位      │
    │ 随便画        │ ───►  │ 落位          │ ──► │ 地名→坐标     │
    └──────────────┘       └──────────────┘     └──────────────┘
              ▲                                        │
              └────────────  反向：拖地图上的点回画布  ───┘
```

**一个动作（落位）同时喂三个视图。** 这是"时空笔记本"该有的样子：
- **画布**是入口（最自由）
- **时间轴**是秩序（结构）
- **地图**是位置（空间）

**不要三个平级面板。** 应该以**画布为主**，时间轴是画布的"背景网格"（原型就是这样），地图是**右下角一个透镜**（拖进去就定位）。

## 五、原型现状

**文件：** `chronicles/prototype/canvas/index.html`（单文件零依赖，双击就开）

**已实现：**
- ✅ 无限画布（空格+拖拽平移、滚轮缩放）
- ✅ 背景时间网格（50 年细线 / 200 年中线 / 500 年粗线带标签）
- ✅ 拖动空白＝画新块
- ✅ 拖动块＝移动；双击＝命名；Delete＝删除
- ✅ Shift + 从一个块拖到另一个块 = 连一条关系线
- ✅ **「落位到时间轴」—— 吸附 + 时代配色 + 年份标注 + 纵向避让 + 620ms 补间**
- ✅ URL 参数 `?demo=1`（乱画态）/ `?demo=org`（落位态），便于分享与截图

**已知不足：**
- 没有撤销/重做
- 没有触摸手势（`pointer` 事件有了，但没做双指缩放，平板/手机不可用）
- 没有持久化（刷新就没了）
- 地图还没接
- 候选 1/2（手势时长、形状即类型）还没做

## 六、建议的开发顺序

```
第 1 步（半天）  持久化 + 撤销重做
  → 让原型变成"能真的用"的东西。没有存档，你不会真的开始记。

第 2 步（半天）  候选 2：形状即类型（圆/条/菱形/虚线框）
  → 极低成本，立刻让"画"有语义

第 3 步（半天）  候选 1：手势时长（线越粗越重要）
  → 「落位」已经能处理区间，"画一条线"只是换了个创建方式

第 4 步（1天）    地图透镜
  → 右下角小地图，把块拖上去＝获得坐标

第 5 步（1天）    候选 3：粘贴即结构化
  → 读书入口
```

> **「乱画 → 落位 → 结构浮现」——这三个动作就是产品本身。**
