## 0. 换电脑要不要「导出文件」？

**设计与代码：不用单独导出，拉仓库即可。**

```bash
git clone https://github.com/HypnosC/SOI.git
cd SOI
git checkout cursor/tapdev-taptap-maker-120b
git pull
```

**不会进仓库、必须在新电脑重做的：**

| 项 | 说明 |
|----|------|
| Maker PAT | 本机 `~/.taptap-maker/`，见根目录 `DEV_CONTINUE.md` |
| Maker MCP | `npx -y @taptap/maker install --ide cursor` 后重启 Cursor |
| AI 套件 | `urhox-libs/` 等 gitignore，需在 `tapDev` 再 `init --app-id …` |
| 聊天记录 | 以本文 + `tapDev/design/*` 为准，不必导出对话 |

## 1. 产品定位与路线

| 项 | 定案 |
|----|------|
| 品类 | 人生策略 + **中心防守塔防** + 轻建造 |
| 主题 | 一生面对欲望、社会规则、考试等节点与意外；**死亡=通关** |
| 时间 | **1 波 ≈ 1 年**；数据影响寿命 |
| 继承 | 可生子；子女继承部分能力/财产；**最多三代** |
| 1.0 剧本 | **当代中国**普遍人生剧本 |
| DLC 以后 | 出生时空（中世纪英国、三国蜀等）换事件表 |
| 平台 | **先 TapTap 移动验证** → 成功后再 PC（优 UI + DLC） |
| 引擎 | TapTap Maker / UrhoX + Lua（现有 `tapDev`） |

成功后再 PC：优 UI、加 DLC；不在 1.0 换 Godot。

---

## 2. 核心循环

```
年龄+1（一年）
  → 事件（阶段短事件 / 大节点 / 意外 / 关系）
  → 建造（塔 + 墙，改地形）
  → 中心防守战（多入口冲向「我」）
  → 结算寿命/钱/压力/flags
……
死亡通关 → 盖结局章 →（可选）子代继承开下一局
```

- 标准一局长约 **25–40 分钟**；有效决策约 30 次；平年可快进，大节点必停。  
- 主卖点：**人生多样性** → 落成「结局图鉴 + 可辨认 build」，不是唯一下完美 roll。  
- **完美人生** = 隐藏殿堂结局；大众追图鉴/成就。

---

## 3. 战场与角色

| 定案 | 说明 |
|------|------|
| **单核 = 我** | 唯一要守的核；漏伤打在寿命/心态 |
| **家 = 场外** | 不做第二核；成就发奖/补贴/剧情（如高考好给一笔钱） |
| **废弃固定单线** | 困难从四面来；多入口 + 寻路冲核 |
| **建造** | 塔（应对）+ 墙/设施（改路）；布局是核心手感 |
| **邻接** | 塔互相增益/冲突 |
| **科技树** | 「人生发展树」三枝：求稳 / 上进 / 欲望 |
| **开局三雕像** | 最多三代前辈烙印，轻加成（抬地板不抬死天花板） |

详见：`battlefield_center_defense.md`、`core_me_family_support.md`。

---

## 4. 人生目标（志向）— 不是开局选

- **立誓前**：自由成长、多线浅试。  
- **关键节点立誓**（主推约 26–32 立业定锚）：选人生目标。  
- **立誓后**：**强化一些，必须放弃一些**（要有体感，UI 写清）。  
- 可选中年极贵「改命」一次。

需重点设计的志向线：

- **经商线**：现金流、信誉、账期/对手怪；过山车。  
- **科研线**：长期进度、截止日期/评审怪；前弱后强。  
- 另有工位上进、求稳、成家、自由、归乡等（与结局簇对齐）。

---

## 5. 事件 / 恋人 / 意外

- **恋人**：关系状态机（追→恋→分）；**结婚是大节点收束**，不是唯一内容。  
- **意外**：独立池，低概率插队，可打断快进。  
- **触发**：大节点窗强制 → 意外检定 → 关系短事件 → 阶段主池。  
- **事件库**：表驱动（id/type/stage/require/weight/choices/results/battle）。  

池：`stage_*` / `major_*` / `love_*` / `family_*` / `accident_*`。

---

## 6. 大节点（约 12 个，必停）

家庭底色 → 小学适应 → 中考 → **高考** → 第一出路 → 感情定锚 → **工作成型** → 住 → **生育** → 中年责任 → 健康 cap → **终局安排**。  

另：**立业定锚（立誓）** 建议纳入或与「工作成型」合并设计。

---

## 7. 结局与成就

- 主结局约 20 + 隐藏「完美人生」：见 `life_endings.md`。  
- **成就系统要做**：探索导航 + 轻 meta（少永久数值碾压）。  
- 留存：结局图鉴 > 成就 > 三雕像 > 完美殿堂。

---

## 8. 数值与塔/敌

- 对齐：`需求DPS ≈ 总血量 / 平均抵达时间`（墙拉长抵达时间）。  
- 塔/敌草案：`towers_enemies_balance.md`（后补 commerce/research 标签与专用怪）。  
- 经商/科研专用怪要跟线，不单换皮。

## 11. 开发机建议开工顺序

1. 按 `DEV_CONTINUE.md` 装好 Maker + 拉齐 kit。  
2. 读本简报 + 上表文档，开新对话把 `tapDev/design/` 丢给 AI。  
3. 重做 **中心防守地图 + 墙/塔建造**（替换固定路径原型）。  
4. 事件表 MVP（大节点 + 阶段短事件）。  
5. 立誓（含经商/科研强化-放弃）。  
6. 结局盖章 + 成就 + 三雕像。
