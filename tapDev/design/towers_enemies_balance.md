# 打工人一生 · 塔 / 敌人 数值骨架（草案）

> 用途：先在表里对齐「标准阵 DPS vs 波次总血量」，再调手感。  
> 单位：1 波 = 1 有效战斗年（平年可短波；大节点年用完整预算）。  
> 状态：草案，系数可改；先锁列含义，再填数。

---

## 0. 对齐用的核心公式（填表时盯住）

```
需求DPS_n ≈ H_n / T_path_n * k

H_n     = 本波敌人总有效血量
T_path  = 敌人从出生点走到终点的秒数（布局越好通常越大）
k       = 难度（0.9 易 / 1.0 标准 / 1.1 难）
```

标准阵：假设「该阶段默认能上场的 5 塔 + 无邻接吃满」的合计 DPS。  
调表顺序：先定敌人 `H_n` 曲线 → 再定塔底座 DPS/造价 → 最后加邻接与升级。

### 2.3 年成长（所有敌 hp、reward 共用）

```
hp_n      = hp_base * (1.05)^(combat_index) * M_stage * M_event
reward_n  = reward_base * (1.03)^(combat_index)
```

- `combat_index`：第几次有效塔防（不是虚岁；幼年自动年可不计）  
- `M_stage` 建议：幼年 0.6 / 求学 0.9 / 起步 1.0 / 立业 1.1 / 中年 1.2 / 收束 1.15  
- `M_event`：平年 1.0；大节点 1.25～1.6（高考、购房、生育、大病）

### 2.4 一波怎么拼（血量预算）

```
H_n = H0 * (1.055)^(combat_index) * M_stage * M_event
```

草案锚点：

| combat_index | 阶段感 | H_n（标准） | 期望标准阵裸 DPS | 期望 T_path |
|--------------|--------|------------|------------------|-------------|
| 1 | 求学初 | 400 | 25 | 18s |
| 5 | 高考年 | 1200 | 45 | 22s |
| 10 | 立业 | 2000 | 55 | 24s |
| 15 | 购房/生育 | 3200 | 65 | 26s |
| 20 | 中年 | 4500 | 75 | 26s |

拼波：用各敌 `hp * count` 加总贴近 `H_n`；精英/Boss 占预算 25%～40%。

**标签克制（简单加算即可）**

| 塔 tags_deal | 对对应 tag 敌人 |
|--------------|-----------------|
| 有克制 | +25% 伤害 |
| 无 | 100% |
| 冲突（如 desire 打 rule） | 可选 -15% |

## 3. 邻接（先 8 条，别做全矩阵）

| # | 条件 | 效果 |
|---|------|------|
| 1 | sleep 邻接任意输出 | 该输出 +8% 伤 |
| 2 | network 邻接 career | career +10% 攻速；network 减速 +15% |
| 3 | cert 打「正在被减速」的敌 | +25% 伤 |
| 4 | saver 邻接 skill | 击杀赏金 +1 |
| 5 | nightowl 邻接 career | 再 +15% 攻速；sleep 在场则两者 -20% |
| 6 | compliance 在场 | rule 标签敌受伤 +20%（或敌特殊削弱） |
| 7 | binge 与 saver 相邻 | 双方经济效果对消 |
| 8 | insurance 靠近终点 2 格内 | 漏怪惩罚 -15% |

全图吃满邻接，总增幅目标：**不超过裸 DPS 的 +35%**。

---

## 4. 调表检查清单

1. 固定标准阵与标准布局，算出裸 DPS。  
2. 用 `H_n / T_path ≈ DPS` 看每年是否在 ±10% 内。  
3. 只开邻接，再看是否超 +35%。  
4. 欲望塔（熬夜灯）单塔效率可以高，但必须在寿命/压力账上讨回来。  
5. 经济塔不进 DPS 公式，进「明年能升几级」。
