# 打工人一生 · 界面方案（塔防为主）

> 前提：一年 ≈ 一波；布局/邻接/科技树是核心操作；人生事件改的是塔、图、修正。  
> 默认：**手机竖屏**（TapTap）。横屏可后做，信息架构先按竖屏定。

---

## 1. 产品句（决定一切排版）

**主屏是战场；人生是顶栏与战前战后的薄层。**

玩家 70% 时间在：**选塔 → 摆阵看邻接 → 开打**。  
对话/大节点是战前插页，不是主 UI。

---

## 2. 界面清单（MVP 只做 6 个）

| # | 界面 | 何时出现 | 一句话职责 |
|---|------|----------|------------|
| A | 战场主屏 | 每年战斗中 | 布局 + 开战 + 看资源 |
| B | 战前编队/事件 | 过年前 | 抽事件、确认上场塔 |
| C | 科技树（发展） | 主动打开或战前点一点 | 解锁/强化塔 |
| D | 人生状态 | 点顶栏数值 | 寿命/欲望/规则详情 |
| E | 死亡结算 | 死亡后 | 通关评价 + 遗产 |
| F | 子代开局 | 有继承时 | 确认继承切片 |

不做：大世界地图、社交、复杂背包、多页商城。

---

## 3. A. 战场主屏（最重要，先画这个）

```
┌─────────────────────────────┐
│ 28岁·立业  寿████░░  钱120  │  ← 顶栏：身份+寿命+钱（压力可点进 D）
│ 第2/3代    本波：月供年      │
├─────────────────────────────┤
│ ▌路径与建造区（主视觉 55%）  │
│ ▌邻接高亮：绿友好 / 红冲突   │
│ ▌终点=「家/自己」            │
├─────────────────────────────┤
│ [工位][证书][饭局][储蓄][早睡]│  ← 上场 5 槽（从已解锁里编）
│  造价60  DPS18  喜:饭局      │  ← 选中塔时一行说明
├─────────────────────────────┤
│ [开战]  [清除]  [发展]  [… ] │
└─────────────────────────────┘
```

### 布局交互（游戏性重点要露在表面上）

1. **点槽选塔 → 点空地建造**；已有塔再点 = 升级/拆除。  
2. **拖拽入场时显示占格 + 射程圈**。  
3. **邻接**：落子瞬间给相邻塔描边（绿/红）+ 一行「工位机枪 攻速+10%」。  
4. **沿用上年阵**：平年默认保留布局，只高亮「可微调」；大节点年地图模版变，强制重排或给迁移费。  
5. **开战前**可自由摆；开战后退回「仅升级/技能」，避免微操过载（MVP）。

### 顶栏信息纪律

常驻最多 **4 个**：年龄阶段、寿命条、钱、本波主题。  
身体/压力/欲望 → 点寿命或「状态」进 D，战场上不摊开。

---

## 4. B. 战前层（事件 + 编队）

每年流程：

```
短事件/大节点弹层  →  （可选）改编队  →  进入战场摆阵  →  开战
```

**短事件**：半屏卡片，2 选项，选完直接进战场或并年。  
**大节点**：近全屏，2～4 选项；选项后果用标签预告：`解锁塔` `改地图` `敌潮标签` `寿命↓`。

编队条：

- 解锁塔图鉴里勾选最多 **5 个上场**。  
- 费用上限（可选）：上场塔造价总和 ≤ 本年带入预算。  

---

## 5. C. 科技树（发展）

单独一页，树状或三列：

```
  求稳          上进          欲望
   │            │            │
 早睡盾        证书炮        熬夜灯
   │            │            │
 医保伞        工位机枪      冲动购
```

- 节点状态：锁 / 可点 / 已点。  
- 点消耗：行动点或大节点成功币（不要第三种货币）。  
- 从战场底栏「发展」进；战中只读或禁止点（MVP 建议战前才能点）。

---

## 6. D / E / F（薄、但要有仪式感）

**D 状态**：列表即可——寿命期望、压力、欲望条、当前规则修正、继承预览。  

**E 死亡结算**（第二招牌屏）：

- 标题：一代结束（年龄、死因一句话）  
- 三列遗产：可传塔/树烙印、钱、人生关键词  
- 按钮：`归档通关` / `让孩子接着`（无孩子则灰掉）  

**F 子代开局**：列出继承了什么（衰减后），确认出生进入第 N 代。

## 7. 视觉怎么出（执行顺序）

### 阶段 1 — 线框（先做）
- 只出 **A 战场** + **B 事件弹层** 灰度线框（Figma/纸笔均可）。  
- 验证：邻接反馈、5 槽、顶栏是否一眼能懂。

### 阶段 2 — 风格钉死
- 关键词：**纪实物件 + 轻矢量**（工牌、成绩单、户口本剪影当塔图标），不要魔幻城堡 TD。  
- 阶段换战场底图色温：校园冷白 / 通勤灰蓝 / 家庭暖纸色。  
- UI 组件极简：底栏、顶栏、一卡片；少圆角胶囊堆。

### 阶段 3 — 动效（少而准）
1. 落塔邻接闪一下绿/红。  
2. 开战路径上敌人出现。  
3. 死亡结算「一生时间轴」短扫过（1.5s）。  

### 阶段 4 — 再扩 C/E/F 高保真

## 8. 和「30 分钟一代」的界面配合

| 年类型 | 界面流程 |
|--------|----------|
| 平年 | 短事件 → 沿用阵 → 一键开战（可进微调） |
| 大节点年 | 大事件 → 可能换地图 → 强制看布局 → 完整波 |
| 岁月静好 | 跳过平年 UI，只打断大节点与溃线 |

## 9. Maker / 实现提示（开发机用）

- 战场层：路径 + 建造格用游戏主视图（Scene 或 NanoVG 地图）。  
- 顶栏/底栏/弹层：`urhox-libs/UI`。  
- 先打通 **A+B** 就能内部试玩；C/E/F 可占位按钮。
