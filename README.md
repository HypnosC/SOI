# SOI

**无知之海 · 探索不止**
<sub>SEA OF IGNORANCE</sub>

</div>

> ### *I am a beacon of knowledge blazing out across a black sea of ignorance.*

「知道自己不知道」，比「以为自己知道」更有用。

SOI 是一条船（春日号），载着几个不同的项目，都指向同一件事 ——
**把模糊的东西变成清晰的结构。**

### 无知编年 CHRONICLES

[`chronicles/`](chronicles/) &nbsp;·&nbsp; **[▶ 打开演示](chronicles/demo/index.html)** &nbsp;·&nbsp; [完整说明](chronicles/README.md)

```bash
# 零依赖、零构建，直接双击
chronicles/demo/index.html
```

- **时间轴 × 地图**：一个块 = 一段时间 × 一片地方，两个投影互相跟随
- **事件隧道**：点一个事件，上为因、下为果
- **叙事模式**：一个事件展开成它自己的子时间线
- **尺度自适应**：从「十年 · 全球」到「一天 · 一座城」，同一个界面
